# beads

## Overview
Packages beads (`bd`), an issue tracker for AI-supervised coding workflows, built from the tagged source `steveyegge/beads` with `toolboxLib.buildGoPackage`. Marked inactive (`_meta.inactive = true`): no new versions are added.

## Interface
- `default.nix`: `builders.default = toolboxLib.buildGoPackage { pname = "beads"; subPackages = [ "cmd/bd" ]; ... }`.
- Versions: `0.60.0` (`_meta.default`), `0.52.0`, `0.51.0`.
- Installs `$out/bin/bd` (`meta.mainProgram`) and symlink `$out/bin/beads`; fish, bash and zsh completions under `$out/share`.
- Cross-package dep: `toolbox.go.versions.${versionData.go}` (Go 1.26.1 for 0.60.0, 1.25.6 for 0.52.0/0.51.0).
- Build inputs: git, pkg-config, icu.

## Invariants
- Each version entry needs `sha256` (`--unpack` hash of `v<version>`), `vendorHash`, and `go` (a version present in `packages/go/data.json`).
- `postPatch` rewrites the `go` line in `go.mod` to the pinned Go's version; `GOTOOLCHAIN = "auto"`.
- Completions are generated by running the built `bd`, so the binary must run on the build host.
- Tests are skipped (`doCheck = false`, set by `buildGoPackage`).

## Side Effects
- Build time only: fixed-output fetches of the source tarball and Go module vendor tree.

## Verification
- Run: `nix build --no-link .#beads.default`
- Run: `nix flake check` (registry gate; pass the `devenv-root` override described in the Verification Checklist of `AGENTS.md`)
